# src/data/ — 【预留】静态数据

> **状态：预留目录**，当前为空。

## 规划用途

存放需要打包进前端的静态数据资源，例如：

- 预置主题模板列表
- 通用的技能图标 / 社交平台映射
- Demo 示例配置（非真实客户）

## 与其它数据位置的区别

- **真实客户数据**放 `users/<客户名>/space.json`（运行时 fetch，不打包）。
- **打包进 bundle 的常量数据**才放这里。

## 约定

- 数据文件用 `.ts`（带类型）导出，便于 tree-shaking；纯静态大体积数据用 `.json`。
- 不放业务逻辑，只放数据。
