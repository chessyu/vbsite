# VBSite 管理后台使用指南

> 本指南面向站长（网站管理员），不需要任何编程基础。
> 管理后台是一个网页工具，用来：**给客户创建网站、修改客户网站、把改好的网站发布上线**。

---

## 一句话理解它怎么工作的

你在管理后台里改内容 → 点「发布」→ 系统自动把内容存起来 → 网站在几分钟内自动更新。中间不需要碰任何代码。

打个比方：

- **管理后台** = 你的「网站制作工作台」
- **编辑链接** = 你发给客户的「临时钥匙」，客户拿到链接就能改自己的网站，钥匙有时效（默认 24 小时），过期自动作废
- **发布** = 把改好的内容「交付上线」，点完之后等几分钟生效

---

## 你需要准备的东西（只需一次）

首次使用前，需要请技术人员（或按下面的指引自己操作）完成 4 项配置。**做完一次就不用再管了。**

| 要准备的 | 是什么 | 在哪里配 |
|---|---|---|
| 管理员密码 | 你登录后台用的密码 | 网站托管平台的设置页 |
| 一串「签名密钥」 | 系统内部用来生成临时钥匙，你不用理解它 | 同上 |
| GitHub 令牌 | 让系统能自动存档和发布网站的一把「总钥匙」 | GitHub 网站上生成 |
| 仓库地址 | 你的网站代码存放的位置，形如 `chessyu/vbsite` | 同上 |

> 详细的配置清单在项目的 `.env.example` 文件里有说明，可以直接交给技术人员照做。

## 日常使用

### 1. 登录管理后台

打开网址：`你的域名/admin`

- 会自动跳到登录页，输入**管理员密码**即可
- 登录状态保持约 12 小时，超时后重新输一次密码就行

### 2. 查看客户列表

登录后就能看到所有客户网站：

- 每个客户一行，显示名字和访问路径（如 `/cheesyu`）
- 点「查看站点 ↗」可以在新标签页预览该客户的网站

### 3. 给客户发一个「可编辑的链接」

想让客户自己改网站内容（比如换头像、改简介）时：

1. 在客户列表中找到该客户，点 **「生成编辑链接」**
2. 出现一串链接，点 **「复制」** 发给客户（微信、邮件都行）
3. 客户打开链接，就能直接编辑自己的网站——**不需要账号、不需要密码**

**关于这个链接，你需要知道：**

- ⏰ 链接默认 **24 小时**后失效，客户要在有效期内完成修改
- 🔒 没有 link 或者链接过期的人打开，只会看到一个「404 页面」，**看不到任何客户资料**（这是故意的，防止有人乱猜链接偷看客户数据）
- 🔁 过期了怎么办？回到列表再点一次「生成编辑链接」，发一条新的就好
- 💡 你自己也能用这个链接——或者直接自己登录后台编辑（见下一条）

### 4. 亲自编辑客户的网站

你也可以不经过客户，直接替客户改：

- 登录后台 → 客户列表 → 生成编辑链接 → 自己打开，进入编辑器
- 或者之后会支持直接从列表点进编辑器（以实际界面为准）

### 5. 新建一个客户网站

有新客户了：

1. 登录后台 → 点右上角 **「+ 新建用户」**
2. 输入客户的**用户 ID**（就是网址里的名字，比如 `demi`，之后客户网站就是 `你的域名/demi`）
   - 只能用小写字母、数字和连字符
   - **起好后不能改**，请想好再填
3. 点「创建并进入编辑器」→ 会打开一个已经预置好基本结构的空白网站

### 6. 使用编辑器（核心界面）

编辑器分成左右两块：

```
┌──────────────────────────────────────────────┐
│  顶栏：客户名 · 链接剩余时间 · 重置 · 发布      │
├────────────────┬─────────────────────────────┤
│   左边：编辑区   │   右边：实时预览              │
│                │                             │
│  [内容结构]      │   客户改这里的内容，          │
│  [主题]         │   右边的网站马上跟着变，       │
│  [空间信息]      │   所见即所得                  │
└────────────────┴─────────────────────────────┘
```

**左边编辑区**有三个标签页：

| 标签 | 管什么 |
|---|---|
| 内容结构 | 网页的各个板块：首屏大标题、关于我、作品画廊、联系方式等。可以增删板块、调顺序、逐个编辑里面的文字和图片 |
| 主题 | 网站的整体风格：浅色/深色、背景颜色、文字颜色、渐变色 |
| 空间信息 | 客户的名字、网站页脚文字 |

**右边预览区**：

- 修改任何内容，右侧**几秒内自动更新**，看到的就是客户最终看到的效果
- 顶部可以切换「🖥 桌面 / 📱 移动」视图——**强烈建议发布前用移动视图检查一遍**，因为大部分访客来自手机

**改文字**：在左边的输入框里直接改就行。

**换图片**（头像、作品图等）：点上传框 → 选本地图片 → 等它上传完，路径会自动填好。图片会自动存档，不用担心丢失。

### 7. 发布上线（最重要的一步）

改完后点右上角 **「发布」**：

- 系统会先自动**检查内容是否完整规范**（比如必填的标题没填，会提示你哪里有问题，改完再发）
- 检查通过 → 显示绿色「已提交 ✓」，同时给一个可以点开的存档链接
- **等 2～3 分钟**，客户的网站就自动更新了

> 💡 发布后想确认？点开客户列表里的「查看站点 ↗」，刷新页面看看。
> ⚠️ 网站更新不是瞬时的，别以为发布失败了反复点——等几分钟再检查。

**没改完怎么办？** 不用发布，直接关掉页面就行。系统会自动保存草稿在浏览器里，下次打开同一个编辑链接继续改。**但要记住：没点「发布」= 客户网站不会有任何变化。**

**改坏了怎么办？** 点顶栏的「重置」按钮，会丢弃所有未发布的修改，回到线上当前版本。

## 常见问题

**问：客户说链接打不开，显示 404？**
答：三种可能——① 链接超过 24 小时过期了，重新生成一条；② 复制链接时没复制完整（链接很长，注意别截断）；③ 客户把链接里的 `?token=xxx` 部分删掉了，让他原样打开。

**问：点了发布，但网站好像没变？**
答：等 2～3 分钟再刷新（手机浏览器可以试试关闭网页重开，避免缓存）。还没变的话，重新登录后台进编辑器，看修改是否还在——在的话说明发布成功了只是缓存，不在的话说明当时没点发布。

**问：发布时提示「配置校验失败」？**
答：有必填内容没填好，提示信息里会写清楚是哪个板块的哪个字段（比如「作品名不能为空」），按提示去补全即可。

**问：不小心删错了板块 / 改乱了内容？**
答：只要**还没点发布**，点「重置」就能全部还原。已经发布过的话，改回正确内容再发布一次即可。

**问：能给客户永久有效的链接吗？**
答：目前链接最长 7 天（默认 24 小时）。永久编辑权限暂不支持，需要时随时重新生成即可——这其实更安全，链接泄露了损失也有限。

**问：客户的图片存在哪里？会不会丢？**
答：所有图片和网站内容一起自动存档（在 GitHub 上），每一版都有记录，不会因为浏览器清理而丢失。

**问：我不小心把管理员密码忘了？**
答：找技术人员在网站托管平台（Cloudflare）的设置里重置 `ADMIN_PASSWORD` 这个配置项。

## 安全须知（请务必阅读）

1. **管理员密码**不要告诉任何人——知道密码就能改所有客户网站
2. **编辑链接**发出去前确认收对人，链接 = 该客户网站的临时钥匙
3. 链接过期是**功能不是 bug**，随时可以重新生成，不用担心
4. 客户资料（照片、联系方式）请仅用于建站目的
